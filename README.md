# Pañchāṅga Explorer

An educational web application for understanding Vedic timekeeping systems.

## Features

- Real-time Panchanga calculations (Tithi, Nakshatra, Masa)
- Interactive visualizations comparing Solar, Lunar, and Tithi systems
- Location-aware calculations
- Educational overview for beginners
- Debug view for verification

## Quick Start

```bash
# Serve locally
python -m http.server 8000
# OR
npx serve

# Open browser
open http://localhost:8000
```
